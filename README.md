# Vaelira

A small HTML and CSS practice project created during my Software Engineering training at WBS CODING SCHOOL.

The project was built to practice basic web development concepts while experimenting with a more personal fantasy-inspired design instead of using a generic example website.

## About the Project

The website is themed around **Vaelira**, a fictional character, and uses her as the basis for a small multi-page website.

The main focus of the project is practicing and experimenting with:

- semantic HTML
- multi-page website structure
- CSS styling
- CSS custom properties
- Flexbox
- responsive design
- media queries
- hover effects
- navigation and layout
- working with images and visual styling

The project is primarily a learning exercise and may continue to change as I learn more about HTML, CSS, and web development.

## Pages

The website currently contains several pages, including:

- Home
- About
- Services
- Contact
- Alchemy Lab

## Technologies

- HTML5
- CSS3
- JavaScript

The Alchemy Lab uses vanilla JavaScript and `localStorage` to save potions in
the browser.

## Image Notice

The character images, favicon, and cursor images used in this project are AI-generated.

They are used solely as visual material for this educational and non-commercial practice project.

The purpose of the repository is to demonstrate and practice web development skills, not to present the generated images as original hand-created artwork.
